权重初始化在神经网络的学习中十分重要:
结合函数表达式以及函数图像进行理解.
假设初始的权重完全相同,不同的神经元只会输出相同的值,以致于最终传递到输出层的值, 不过是使用单个权重相同的神经元传递的值的倍数,
表达能力退化为一个一维非线性函数的倍数(多个相同的Wx相加变为一个Wx,再被激活),倍数可学,权重调参后等效,
学不到不同的特征,失去了加深神经网络的意义.
只拟合有限个点时，一个足够灵活的一维非线性函数（在投影不重合的前提下）也可以,
但要在整个定义域上一致逼近任意连续函数，固定单方向的函数做不到——它对垂直于该方向的变化完全不敏感。
只有用足够多、方向彼此不同的非线性函数做线性组合,才能覆盖所有方向、逼近任意连续函数.
多维线性函数相加,再激活后变为非线性函数(单个神经元),
多个不同的非线性函数乘输出权重相加做线性组合(下一层),就可以逼近任意连续函数.
(理论上单隐藏层就可以做到,但是函数复杂时不现实多层可以显著减少参数量并提高效率)



权值衰减可以抑制过拟合:
同是输入两个数,权值较大的神经网络,最后的输出的差值较大,尤其输出层的激活函数还是softmax时.
大权重意味着网络对输入的微小变化极其敏感——输入扰动一点，输出就剧烈变化.
模型通常只能很好拟合训练数据,测试数据若稍微偏移一点,拟合函数已经剧烈变化偏移,模型泛化能力往往较差.


权值衰减会在原始训练损失中，加入一项权重平方和的惩罚：
总loss = loss + (λ/2)‖W‖²
其中：
λ：权值衰减的强度； ‖W‖²：所有权重的平方和； 数据损失：模型原本的训练损失。
加入惩罚项后，权重对应的梯度变为：
总loss梯度 = loss梯度 + λW
代入梯度下降公式：
W ← W − η（loss梯度 + λW）
整理后得到：
W ← (1 − ηλ)W − η × loss梯度
这个更新过程可以分成两步理解：
先计算 (1 − ηλ)W，让原来的权重按比例向零收缩;再根据loss的梯度进行正常更新。
因此，权值衰减的直接作用就是： 在训练权重的同时，持续抑制权重无限制增大，从而降低过拟合风险。
权值衰减属于正则化。上面这种惩罚权重平方和的形式，通常也称为 L2 正则化。


权值过大或过小的影响:
另外,若是权值过大,前向传播时累乘可能会数值爆炸,即便对于输入数据x进行归一化也只能缓解,
因为多层神经网络W是累乘的,会使数值指数级增加,可能导致数值溢出.
反向传播求关于W的梯度通过链式法则也要乘W(忘了可以画计算图的反向传播辅助理解),可能导致梯度爆炸
若是权值过小,前向传播时累乘可能会导致数值过小,权值更新之后loss几乎没有变化,
同时反向传播时求梯度时可能导致梯度消失,让学习效率极低,最终导致欠拟合.
不同的激化函数会有不同的效果呈现:
对于sigmoid,权值过大时可以有效压低,包括函数自身对于前向的压低,也有函数导数较小对于反向的压低,
但是权值过小时,sigmoid显然起的是反作用,让前向数值集中在0.5附近,可能减慢特征分化和学习,
降低有限训练内的有效表达能力,但不等于永久限制模型的表达能力.同时反向梯度更易消失.
对于ReLu,在正区间不压缩数值、不衰减梯度,因此不能防止数值或梯度爆炸(权值较大);在负区间则直接阻断信号(权值较小).


激活函数的饱和区大小与导数大小事关梯度消失与模型表达能力:
饱和区指的是函数输出值近似的区域,此区域输出对输入不敏感,导数接近零,
通过链式法则进行反向传播累乘会使梯度趋于零,导致梯度消失无法进行更新.与饱和区相对应的是线性区.
sigmoid函数,不仅饱和区极大(使用标准差为1的正态分布进行权重初始化,经过全连接层输入很可能落在饱和区里),
使用标准差为0.01的正态分布(取值与均值0的平均偏离为0.01)可以缓解梯度消失,
但是sigmoid函数线性区小,权重取值受限,起始很可能取值近似学到相同特征.
使用Xavier初始值效果会更好,但是sigmoid函数导数最大值仅为0.25,神经网络的深度稍微增加后也难以避免梯度消失的问题.


He初始化:
此处只讨论前向传播:
z = w₁x₁ + w₂x₂ + … + wₙxₙ, ReLU(z)
首先我们目的是防止W过大或过小,而激活值膨胀或消失的问题与之实际上是同一种描述.激活值数量级不变,等效于W取值合适.
衡量激活值的数量级,一般使用激活值平方的均值,不受正负影响.根据方差公式E[h**2]=(E[h])**2+Var(h),
假设均值为零时,方差等于激活值平方的均值.因此初始化时令均值为零,后续以激活值的方差直接进行衡量.
激活值方差 = 输入神经元连接数 * W方差 * 激活函数方差比例 * x方差,x方差视为上一个激活值的数量级.
因此令输入神经元连接数 * W方差 * 激活函数方差比例约等于1,那么W就可以取适合的值.
ReLu的方差比例是0.5,最后可得W方差等于2/输入神经元连接数.W的初始化就可以使用均值为0,方差为2/输入神经元连接数的正态分布
(反向传播同样会受到权重和激活函数导数的逐层缩放，因此初始化还需要避免梯度随深度爆炸或消失；He有fan-in 与 fan-out版本,
Xavier 会综合考虑 fan-in 与 fan-out。相关严格推导暂不展开。)
