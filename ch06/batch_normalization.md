批归一化:
目的:控制神经链接输入值x的尺度与大小,避免梯度尺度不一和前向传播时数值过大或过小
(对于sigmoid等S型激活函数会落到饱和区,影响反向传播的学习效率;
对于ReLu来说,过小使神经元输出为零,导数为零,关闭了该神经元的反向传播通道,
过大如果没有进行适当的权值初始化,可能使数值爆炸)

核心式子依旧是:激活值方差 = 输入神经元连接数 * W方差 * 激活函数方差比例 * x方差,
假设输入神经元连接数 * W方差 * 激活函数方差比例交由权值初始化约等于1控制得当,
那么我们通过控制x均值为零,不仅可以辅助权值初始化的进行,同时控制了x的大小,满足了目的;
此外,由于反向传播的梯度最后需要乘神经链接输入值x,梯度尺度与x相关,还需要控制x的方差.
又因为梯度尺度不统一的话,每一层的学习率也无法统一.
不同层的梯度尺度差异过大时，同一个学习率可能无法同时适合所有层，导致部分层不稳定、部分层学不动。
梯度大的层更新过猛，可能反复越过较优点(可以看作反复越过最优点在那几个维度上的投影)，造成 loss 振荡甚至发散；
梯度小的层更新过慢，长期接近原地不动；
所以我们控制x的方差为1,不仅有助于缓解梯度尺度差异,提高学习效率,也进一步约束了部分x值过大或过小的情况.
但是,如果对于x与激活值的尺度进行了缩小,就又不能很好地拟合数据.
我们发现仿射映射像一个开关,可以恢复先前的尺度,或者根据自身需求达到需要的尺度.


具体实现:
归一化:
x̂ᵢ = (xᵢ − μ) / √(σ² + ε): μ为xᵢ均值,(xᵢ − μ)让xᵢ均值偏移等于0; 
σ²为xᵢ方差,/ √(σ² + ε)让xᵢ方差近似为1;ε是极小数防止分母为零无意义或者过小无穷大.
方差归一化推导：
Var(z) = Var( (x − μ) / σ ) = (1 / σ²) · Var(x − μ) = (1 / σ²) · Var(x) = (1 / σ²) · σ² = 1
用到的两条方差性质：
① 减去常数不改变方差（平移不改变"胖瘦"）：
Var(x − μ) = Var(x) = σ²
② 乘以常数 c，方差乘 c²；此处 c = 1/σ，故方差乘 1/σ²：
Var( (1/σ)·(x − μ) ) = (1/σ²) · Var(x − μ)

仿射映射:让网络自行学习归一化后的缩放和平移，同时保留表示自由度，不一定恢复为归一化前的分布。
下面以恢复原有分布为例:
yᵢ = γ · x̂ᵢ + β,将x̂ᵢ = (xᵢ − μ) / √(σ² + ε)代入得:yᵢ = γ · (xᵢ − μ) / √(σ² + ε) + β,
显然令γ = √(σ² + ε), β = μ,可以让yᵢ=xᵢ,恢复到原来的尺度.

BatchNorm 放在激活函数前:
sigmoid:可以先调整预激活值的尺度，使其更少落入饱和区，从而让激活函数导数保持在较合适的范围
ReLu:控制预激活值的尺度，降低绝对值过大造成数值失控的风险；
调整预激活值的均值和分布，降低大量神经元长期位于负区间、持续输出零的风险。

前向传播：
x → 全连接层：z = Wx + b → BatchNorm：y = γx̂ + β → 激活函数：a = φ(y)
反向传播：
梯度先经过激活函数，到达 BatchNorm；
在 BatchNorm 层计算 γ、β 的梯度，更新归一化层自己的 γ、β；
梯度继续穿过 BatchNorm，到达全连接层的 z；
再根据 z 的梯度计算 W、b 的梯度，更新全连接层的权重。
