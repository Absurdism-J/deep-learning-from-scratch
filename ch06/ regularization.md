过拟合指的是只能拟合训练数据，但不能很好地拟合不包含在训练数据中的其他数据的状态。
产生过拟合的原因是模型参数多且训练数据少,参数多提高了模型的拟合能力,训练数据少时也可能因为模型参数少表达能力不足而欠拟合
训练数据少会让模型更少学习到泛化的特征,学到较多仅限于训练数据的特征.
正则化是抑制过拟合的技巧.

权值衰减:
W越大,网络对输入的微小变化极其敏感,模型泛化能力往往较差.
W越小可能使得梯度更新小,可能导致模型欠拟合.

通用形式:
每个分量独立更新：
w_ij ← w_ij − η( ∂L/∂w_ij + ∂R/∂w_ij )
三种正则化的区别只在于 ∂R/∂w_ij。

L1 正则化:
R_1 = λ · Σ_ij |w_ij|  (权值分量绝对值之和)
权值分量各自更新: w_ij ← w_ij − η·∂L/∂w_ij − ηλ·sign(w_ij)
其中 sign(w_ij) 在 w_ij > 0 时为 +1，w_ij < 0 时为 −1，w_ij = 0 处取次梯度（通常取 0 或 [−1, 1] 中某值）。
每一步在原始梯度更新之外，额外减去一个固定大小ηλ的项，方向朝向零。
ηλ大小固定,小分量容易被推到零；当原始损失梯度不足以再次把它推离零时，该分量可以保持在零，因此 L1 更容易产生稀疏解。


L2 正则化:
R_2 = λ · Σ_ij w_ij²  (权值分量平方和)
权值分量各自更新: w_ij ← w_ij − η·∂L/∂w_ij − 2ηλ·w_ij

这就是“权值衰减”名字的来源：每一步先把 w_ij 乘一个略小于 1 的系数 (1 − 2ηλ)，再按原始梯度更新。
额外项 2ηλ·w_ij 与分量自身大小成正比，大分量衰减多，小分量衰减少。


L∞ 正则化:
R_∞ = λ · max_ij |w_ij|
权值分量各自更新: 
若 |w_ij| = max_{k,l} |w_kl|：
w_ij ← w_ij − η·∂L/∂w_ij − ηλ·sign(w_ij)
否则： w_ij ← w_ij − η·∂L/∂w_ij
只有当前绝对值最大的分量额外减去 ηλ·sign(w_ij)，其余分量只按原始梯度更新。
多个分量并列最大值时需按次梯度处理.

注意:权值衰减实际上改变了损失函数,使最小值(谷底)发生偏移.要控制λ不要太大,不然很可能导致欠拟合.


Dropout:
Dropout 要解决的核心问题是过拟合，具体表现为神经元之间形成固定的共适应：
某些神经元总是搭配出现、互相依赖，网络把训练数据的细节记在特定的神经元组合上，换一批数据就失效。

下面以Inverted Dropout为例进行原理分析:
训练阶段: 对某层每个神经元，独立地以概率p丢弃、以概率1−p保留。被丢弃的输出置零，保留的输出除以(1−p)。
这一步同时做了两件事：
随机置零：每次前向传播丢弃的神经元组合不同，下一层不能依赖某个固定邻居，打破共适应。
每次训练相当于采样一个不同的子网络。原网络有N个神经元，就有2^N种可能的子网络.
(每个神经元只有保存和丢弃两种状态,和内存的地址编码方式同样的逻辑理解,一种子网络一种编号)
保留值放大：把保留的输出除以 (1−p)，补偿被丢弃的那部分信号。
测试阶段: 所有神经元保留，输出不缩放，直接是完整网络的输出。

尺度控制:此处学习/训练阶段输出除以(1−p)是为了控制尺度统一. 
同一个神经元，每次前向传播时丢不丢是随机的, 所以它的实际输出是一个随机变量。期望就是这个随机变量在大量重复下的平均值。
根据E[训练输出] = x * (1 − p) + p * 0 = x * (1 − p).由于我们训练时的输出尺度是x * (1 − p),后续是受到这个尺度
的影响进行梯度更新的,最终训练出来的权值会拟合这个输出尺度.若是测试时的输出尺度不统一,则很可能会欠拟合.
Inverted Dropout选择在训练阶段将预期E[训练输出]除以(1−p),在测试阶段正常输出x,从而保证尺度一致,权重可以适应两者.
